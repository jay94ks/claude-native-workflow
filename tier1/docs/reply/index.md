> 발급되며 별도 파일을 만들지 않는다 — 답변 대상 문서 안의 "## 답변 기록"
> 섹션에 `### RP-XXXXX` 앵커로 직접 적힌다(`docs/PROTOCOL.md` 6절). 답변이
> 입력되면 이 목록에서 제거하고, 처리 결과는
> [docs/logs/index.md](../logs/index.md)에 기록한다.
